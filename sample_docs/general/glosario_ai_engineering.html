Glosario de AI Engineering

Términos que aparecen a lo largo de las pre-entregas, explicados en criollo.

Async / await

Una función async def puede pausarse con await mientras espera una respuesta de red y dejar que el event loop atienda otras tareas. Mezclar una llamada bloqueante (por ejemplo requests.get o time.sleep) adentro de una corrutina congela todo el loop: hay que usar httpx.AsyncClient, asyncio.sleep o el SDK async oficial del proveedor.

LCEL

LangChain Expression Language. Compone pasos con el operador |: prompt | llm | parser. Cada paso es un Runnable con invoke, ainvoke, stream y batch.

Chunking

Partir un documento en fragmentos antes de indexarlo. Se mide en tokens, no en caracteres, porque el límite del modelo de embeddings está en tokens. Un solapamiento (overlap) de 10 % evita cortar una idea a la mitad.

Búsqueda híbrida

Combina BM25, que encuentra coincidencias exactas de palabras (nombres de funciones, siglas), con búsqueda vectorial, que encuentra textos de significado parecido. Los rankings se fusionan con Reciprocal Rank Fusion (RRF): cada documento suma peso / (60 + puesto) en cada lista.

Grounding

Una respuesta está fundamentada (grounded) cuando cada afirmación se puede rastrear a un fragmento recuperado. Si no hay fragmento que la respalde, el sistema tiene que decir que no lo sabe en lugar de inventar.

Supervisor

Nodo de un grafo multi-agente que solo decide: lee el estado compartido y elige qué especialista trabaja después. Los especialistas nunca se llaman entre sí; siempre vuelven al Supervisor.

Checkpointer

Componente de LangGraph que guarda el estado del grafo después de cada paso, asociado a un thread_id. Con un checkpointer persistente (SQLite, Redis, Postgres) una conversación sobrevive a un reinicio del servidor y un grafo interrumpido se puede reanudar con Command(resume=...).

Human-in-the-loop

Pausa deliberada del grafo con interrupt() hasta que una persona aprueba o rechaza. Se reserva para acciones con efectos difíciles de deshacer.

Observabilidad

Registrar trazas (traces) y spans de cada llamada al LLM, herramienta y nodo para poder explicar qué pasó en una ejecución: latencia, tokens, costo, entradas y salidas. Arize Phoenix recibe las trazas por OpenTelemetry.
